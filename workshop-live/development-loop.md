# The Development "Loop"
- Discuss
- Plan
- Execute
- Review

---

## How to make a big app? by small and simple dev loops
- a Huge App
	- Feature 1: `Discuss -> Plan -> Execute -> Review`
	- Feature 2: `Discuss -> Plan -> Execute -> Review`
	- Bug 1: `Discuss -> Plan -> Execute -> Review`

---

## remember
- Reliable results come from short loops, not one giant prompt
- Do things in small changes, within large phases
- Per feature: complete one loop, then commit.
