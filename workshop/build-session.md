# Module 6: Hands-On Build Session
**12:15 PM — The Main Event (60–90 min)**

This is where it all comes together. Attendees apply everything they've learned to build something real.

## 6.1 Exercise Structure

Pick an exercise tier appropriate to each person:

| Tier | Audience | Task |
|------|----------|------|
| **Tier 1: Explorer** | Technical non-dev | Use claude.ai to build a working web app from a single description. A tool relevant to the company (e.g., internal calculator, form builder, dashboard). |
| **Tier 2: Builder** | Junior developer | Add a feature to the sample repo using Claude Code. Must write CLAUDE.md first, plan before coding, and run tests. |
| **Tier 3: Architect** | Experienced dev | Refactor a messy module using the full agentic loop: plan, implement in steps, add tests, review diffs. Bonus: set up an MCP server. |
