# Build Session: Steps & Challenge

## 6.2 Exercise Steps (For All Tiers)

1. Write your CLAUDE.md / project context (5 min)
2. Define the feature clearly in 2–3 sentences (5 min)
3. List constraints and non-goals (5 min)
4. Ask the agent to propose a plan. Review it. (10 min)
5. Implement in steps, reviewing each step (30–45 min)
6. Run tests / verify the output works (5–10 min)
7. Debrief: What failed? Where did it hallucinate? Where did clarity fix the problem? (10 min)

<div class="ws-callout ws-callout-tip">
<strong>Facilitator Role During Build Session</strong><br><br>
Float between attendees. Watch for common mistakes:
<ul>
<li>Giving the agent too much at once ("build the whole thing")</li>
<li>Not reading the agent's output before accepting</li>
<li>Skipping the planning step</li>
<li>Getting stuck in a failure loop (teach them to use <code>/clear</code> or Git revert)</li>
</ul>
When someone hits a failure, DON'T fix it for them. Walk them through course-correcting. That's the real skill.
</div>

## 6.3 The "Zero Manual Code" Challenge (Optional)

For pairs or teams: challenge them to build their feature writing **zero lines of manual code**. Everything must be done through agent steering.

<div class="ws-callout ws-callout-key">
This forces them to develop the prompting and control skills rather than falling back to typing code themselves.
</div>
