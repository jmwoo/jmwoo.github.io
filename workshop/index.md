# Vibe Coding Workshop

## From Line-by-Line to Steering Agents

**Facilitator Guide & Lesson Plan**

Half-Day Workshop (3.5–4 hours)

**Audience:** Mixed technical levels (junior devs, technical non-developers)

---

### What You'll Learn

1. What agentic/vibe coding is and when to use it
2. How to set up and configure Claude Code
3. How to write effective CLAUDE.md files to steer agent behavior
4. The plan-execute-review workflow for real coding tasks
5. MCP (Model Context Protocol) and how it extends agent capabilities
6. Failure modes, guardrails, and when human judgment is essential
