# Module 1: The Mindset Shift
**9:00 AM — Mental Model & Why This Matters (30 min)**

## 1.1 What Vibe Coding Actually Is

Start with the origin: Andrej Karpathy coined the term in February 2025. The core idea is moving from writing code line-by-line to describing outcomes and steering an AI agent.

Frame the shift using three contrasts:

| Old | New |
|-----|-----|
| Syntax thinking | Constraint thinking |
| Writing code | Shaping behavior |
| Manual line-by-line | Outcome specification |

<div class="ws-callout ws-callout-key">
<strong>Important nuance:</strong> This is NOT "no-code." You still need to understand what good code looks like. The difference is you're now a technical director, not the person holding the camera. You review, guide, and course-correct.
</div>

## Live Demo: The "Wow Moment" (5 min)

Open Claude Code in a terminal. Build something simple but impressive in real-time. Example:

> "Build me a REST API with Express that has CRUD endpoints for a todo list, with input validation and error handling."

Let them watch it scaffold files, write tests, and run them. This hooks the room.

<div class="ws-callout ws-callout-tip">
<strong>For non-dev audience:</strong> Use claude.ai artifacts to build a working React app from a single prompt.
</div>

## 1.2 The Three Layers of Agentic Coding

Present this as a maturity model they'll progress through today:

| Layer | What It Is | Analogy | Result Quality |
|-------|-----------|---------|----------------|
| Prompts only | Chat with an LLM | Asking a stranger for directions | Smart autocomplete |
| + Context files | CLAUDE.md, project docs | Briefing a new hire | Capable junior dev |
| + Tools (MCP) | Filesystem, Git, APIs, DB | Junior dev with access to the building | Autonomous contributor |

<div class="ws-callout ws-callout-key">
<strong>Key teaching point:</strong> Each layer dramatically increases capability. Today we'll cover all three.
</div>
