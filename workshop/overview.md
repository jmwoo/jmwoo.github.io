# Workshop Overview

This workshop takes technical employees from zero agentic coding experience to building real features with AI agents in a single session. The focus is practical: attendees will leave with working mental models, configuration files, and hands-on experience they can apply Monday morning.

## Learning Objectives

By the end of this workshop, attendees will:

1. Understand what agentic/vibe coding is and when to use it (and when not to)
2. Be able to set up and configure Claude Code or similar tools
3. Write effective CLAUDE.md / agents.md files to steer agent behavior
4. Apply the plan-execute-review loop to real coding tasks
5. Understand MCP (Model Context Protocol) and how it extends agent capabilities
6. Know the failure modes, guardrails, and when human judgment is essential

## Audience Notes

This plan accommodates mixed skill levels. Throughout the workshop, you will see callout boxes for how to adjust for different audiences:

<div class="ws-callout ws-callout-tip">
<strong>Junior Developer:</strong> Can write code, familiar with Git and terminal basics. Focus on workflow and control patterns.
</div>

<div class="ws-callout ws-callout-tip">
<strong>Technical Non-Developer:</strong> Comfortable with computers, may know some scripting. Focus on Claude.ai artifacts, prompt patterns, and the conceptual model.
</div>

<div class="ws-callout ws-callout-tip">
<strong>Other Technical Staff:</strong> Adjust based on their comfort level. The hands-on exercises have multiple difficulty tiers.
</div>

## Key Principle

<div class="ws-callout ws-callout-key">
Don't teach "prompt tricks." Teach <strong>determinism, constraint specification, iterative loops, and verification patterns</strong>.<br><br>
Engineers respect rigor. Frame this as a new engineering discipline, not magic.
</div>
