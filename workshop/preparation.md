# Pre-Workshop Preparation

## Send to Attendees (Thursday)

Send setup instructions the day before so Friday starts smooth:

1. Install Claude Code: `npm install -g @anthropic-ai/claude-code` (requires Node.js 18+)
2. Create an Anthropic account and ensure API access or a Claude Pro/Max subscription
3. Install VS Code or their preferred editor
4. Ensure Git is installed and configured
5. Have a project idea or problem in mind (even a small one)

<div class="ws-callout ws-callout-tip">
<strong>For Non-Developers:</strong> If someone can't install Claude Code, have them use claude.ai directly. The concepts (context management, iterative prompting, plan-then-execute) work in the web interface too. Artifacts in claude.ai are an excellent entry point for non-devs.
</div>

## Facilitator Prep

- Prepare a sample repo relevant to the company's domain (something simple but real)
- Have a pre-written CLAUDE.md ready to show (good example and bad example)
- Test your demo end-to-end on the actual WiFi/network you'll be using
- Have backup API keys and a mobile hotspot ready
- Pre-load a few MCP servers to demo (filesystem, GitHub are good starters)
- Prepare the hands-on exercise repo and push it to GitHub
