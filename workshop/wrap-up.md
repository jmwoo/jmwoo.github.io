# Module 8: Wrap-Up & Resources
**1:35 PM — Framework for Continued Learning (15 min)**

## 8.1 The Maturity Model

Leave them with a progression path:

| Level | Stage | What You Can Do |
|-------|-------|----------------|
| 1 | Prompting | Chat with AI, get code snippets, ask questions |
| 2 | Structured Context | CLAUDE.md, plan-first workflow, scoped sessions |
| 3 | Tool Augmented | MCP servers, sub-agents, custom slash commands |
| 4 | Workflow Programming | Custom commands, hooks, automated pipelines |
| 5 | Autonomous Pipelines | Multi-agent orchestration, CI/CD integration, headless mode |

<div class="ws-callout ws-callout-key">
Today we got everyone to at least Level 2, with exposure to Level 3. The rest comes with practice.
</div>

## 8.3 Common Q&A

- **"How much does this cost?"** → Claude Pro ($20/mo), Max ($100–200/mo), and API pricing
- **"Is our code sent to Anthropic?"** → Explain the data handling and privacy policies
- **"Can this replace developers?"** → No. It amplifies them. Someone still needs to review, architect, and make judgment calls.
- **"What about Cursor / Copilot / other tools?"** → The skills transfer. Context management is the meta-skill.
